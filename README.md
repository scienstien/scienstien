Engineering student and developer working across physics simulations, computer vision, ML systems, aerospace software, and web development. I build with C++, Python, JavaScript, SQL, OpenCV, SFML, and modern web tools, with a focus on YOLO/CNN-based vision, real-time pipelines, interactive interfaces, and simulation-heavy engineering projects.

- Interactive frontend work: clean UI, motion, 3D web experiences, and data visualization
- Turbomachinery, propulsion, and computational design workflows
